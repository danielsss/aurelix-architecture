统计与限制的口径不同

在线设备页面按套餐汇总所有购买者并对 IP 去重；限制为每位用户的套餐实例独立分配名额，跨节点与协议合并。同一公网出口可能对应多台物理设备，IP 数不等于真实硬件数量。

Redis 与 MongoDB 各保存什么

Redis 保存节点观测：非空成功快照替换并重置 300 秒 TTL；成功空快照删除数据 key、元数据保留“确认空”；失败不续期旧数据。MongoDB 保存允许、宽限、阻断 IP 和节点目标及确认，仅在状态变化时写入。

下发不等于已生效

规则按“用户 email AND 来源 IP”匹配并路由到 blackhole。Control 收到健康且 revision 匹配的配置结果后才确认应用；节点离线保留待应用或待撤销。首次补齐 Xray 管理配置可能需要重启，后续纯路由变更可动态应用。

撤销与现有连接

被阻断 IP 消失可能是规则造成，不能据此解封。真实空位、提高上限、不再限制或授权失效等条件触发撤销，仍须先持久化再下发。阻断限制新连接，不能保证立即终止已有长连接。

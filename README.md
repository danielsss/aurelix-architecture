# Aurelix Architecture

[Open the architecture diagram](https://danielsss.github.io/aurelix-architecture/)

Standalone architecture diagram generated from the Aurelix working tree on November 19, 2026, including uncommitted changes present at generation time. It is a static snapshot, not a live view of the application or confirmation of production deployment.

The page describes the Web, Control, Node Agent, Xray, storage and authorization boundaries. Source paths and line numbers are included for reference; the private source code and local evidence snapshot are not published here.

## Publishing

GitHub Pages serves the root of the `main` branch. Update `index.html` and push to `main` to publish a new diagram. `.nojekyll` disables Jekyll processing.
